# Tiny Factory

카메라로 물체를 인식해 정상품과 불량품을 분류하는 작은 스마트 공장입니다.
MFC로 만든 프로그램이 컨베이어 벨트, 로봇팔, 운반차를 제어합니다.

| 항목 | 내용 |
|---|---|
| 구분 | 졸업 작품 (최우수상 수상) |
| 개발 기간 | 2024.11 |
| 사용 기술 | C++, MFC, OpenCV (YOLO), Arduino, 시리얼 통신, HTTP |
| 실행 영상 | https://www.youtube.com/watch?v=Ssp9-5lVbss |

## 동작 흐름

```
카메라 → YOLO 인식 → WorkManager 판정
                         ├─ 정상품: 컨베이어 계속 진행 → 로봇팔이 정상 위치로 이동
                         └─ 불량품(모양, 색상 다름): 컨베이어에서 밀어냄 → 로봇팔이 불량 위치로 이동
                                                     → 운반차 출발 (HTTP)
```

## 주요 구현

### 장치별 스레드 분리
- 카메라 출력, YOLO 인식, 컨베이어 벨트, 로봇팔 통신을 각각 별도 스레드(`AfxBeginThread`)로 돌려 UI가 멈추지 않게 했습니다.
- 스레드에서 UI를 직접 건드리지 않고 `PostMessage`로 메인 다이얼로그에 결과를 알립니다.

### 매니저 구조
- `WorkManager`: 인식 결과를 받아 컨베이어, 로봇팔, 운반차에 작업을 지시합니다.
- `DataManager`: 정상품과 불량품 개수를 집계합니다.
- `LogManager`: 작업 로그를 남기고 파일로 저장합니다.
- 여러 스레드가 함께 쓰는 매니저는 싱글톤으로 만들고 `std::mutex`로 보호했습니다.

### 장치 통신
- 컨베이어 벨트와 로봇팔(아두이노)은 시리얼 통신(115200bps)으로 명령 문자열을 주고받습니다.
- 운반차는 Wi-Fi 모듈에 HTTP GET 요청(`/start`, `/wait`)으로 제어합니다.

### 객체 인식
- OpenCV DNN으로 직접 학습한 YOLO 모델을 불러와, 정상품(NORMAL), 모양 불량(DIFFERENTSHAPE), 색상 불량(DIFFERENTCOLOR)을 구분합니다.
